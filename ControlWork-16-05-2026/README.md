Что сделано

- Однопоточный вариант —  циклом
- Многопоточный (Callable) — разбиваем на куски, каждый поток считает свою часть
- Многопоточный (Lock)— потоки складывают результат в общую переменную через ReentrantLock

Мои резы

Однопоточный -  медленно 
Callable - быстро 
 Lock - средненько 


Lock медленне тк Потоки ждут друг друга, когда добавляют к общей сумме.  
А в Callable каждый считает сам за себя, а потом просто складываем.

Вывод
Лучше не синхронизировать общую переменную, а возвращать результаты отдельно.
